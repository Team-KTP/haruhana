# Dev Log

프로젝트를 진행하며 겪은 트러블슈팅, 설계 결정, 기술 분석, 회고를 기록한다.

---

## 디렉토리 구조

```
dev-log/
├── 원천데이터.md          ← 이력서·포트폴리오 원천 데이터
├── 트러블슈팅/            ← 문제 발생 → 원인 분석 → 해결
├── 설계결정/             ← Why를 중심으로 한 기술적 의사결정
└── 기술분석/             ← 아키텍처·멀티스레드·성능 심층 분석
```

---

## 템플릿

각 문서는 아래 형식을 따른다.

```
> 카테고리 / 날짜 / 관련 PR

## 배경
## 문제 / 목표
## Before
## After
## 왜 이렇게 했는가
## 배운 점 / 회고
```
